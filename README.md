# relay-sh Homebrew Tap

Homebrew tap for the Relay CLI.

```bash
brew install relay-sh/tap/relay
```

If Homebrew fails to extract the download, use the install script instead (Linux and macOS):

```bash
curl -fsSL https://docs.userelay.sh/install.sh | bash
```

Formulas here are updated automatically by GoReleaser from [relay-sh/userelay-cli](https://github.com/relay-sh/userelay-cli) on tagged releases, which also publish their binaries as GitHub Releases on this repository.
